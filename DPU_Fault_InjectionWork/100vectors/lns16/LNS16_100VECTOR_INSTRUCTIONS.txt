../generated_fp8_vectors_100/real_vectors.txt

LNS16 format:
- total width: 16 bits
- wE = 4
- wF = 9
- scale = 512
- zero = 0000
- normal finite = bits 15:14 = 01, bit 13 = sign,
  bits 12:0 = signed fixed-point log2 magnitude
- minimum normal magnitude = 2^-8 = 0.00390625
- smaller source magnitudes quantize to zero

python script1_generate_lns16_vectors_100.py
